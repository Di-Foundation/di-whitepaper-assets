# DI Whitepaper Assets

The public visual library for the DI Whitepaper. It contains DI brand images and bilingual diagrams illustrating the ecosystem architecture, Agent network, compute flows, economic flows and Event Engine workflow.

## Asset collections

- [Brand images](./assets/): DI logo and homepage banner.
- [English diagrams](./en/): illustrations with English labels.
- [Chinese diagrams](./cn/): illustrations with Chinese labels.

For the accompanying explanations and current product context, read the [DI Whitepaper](https://whitepaper.di.xyz/) or browse its [source chapters](https://github.com/Di-Foundation/di-whitepaper).

## 关于本仓库

本仓库收录 DI 白皮书的公开视觉素材，包括品牌图片及中英文图解，涵盖生态架构、智能体网络、算力流程、经济流转和 Event Engine 工作流程。

- [品牌图片](./assets/)：DI 标识与首页横幅。
- [英文图解](./en/)：英文标注的说明图片。
- [中文图解](./cn/)：中文标注的说明图片。

图片对应的说明与当前产品信息，请参阅 [DI 中文白皮书](https://whitepaper.di.xyz/zh/) 或 [白皮书源文档](https://github.com/Di-Foundation/di-whitepaper)。
